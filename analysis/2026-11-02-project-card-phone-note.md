PROJECT CARD
(copy this into your phone notes and pin it)

----------------
STEP 1: BEFORE I START
(30 seconds. Only 2 questions.)

1) Am I EXPLORING or MAKING?

EXPLORING = I'm learning what is possible. I can try lots of things. It's OK to not have an end product yet.

MAKING = I'm finishing ONE thing. No new ideas until it's done.

2) What is the ONE thing I want to find out (exploring) or finish (making)?

Example: "Can AI and code make a character that moves?"

That's all I need to start.

----------------
STEP 2: WHILE I WORK

- Break it into small parts.
Example for an animation: character, movement, text, background, voice, sound, put it together.

- Each part gets 5 tries MAX.
After try 5, pick the best one and move on.

- When a part is done, tick it. Don't go back to it.

- A new idea pops up?
Type "PARK: (the idea)" in the same chat. One line. Keep going. I'm not doing it today.

----------------
IF I'M MAKING (finishing one thing)
Before I start, write 3 to 5 checks for "done."
Example: character looks the same in every scene / text is readable / 20 seconds long / has sound.
When every check is ticked, it's DONE. I can't add new checks.

----------------
IF I FEEL STUCK OR WORTHLESS

Ask myself:
- Which part am I on?
- How many tries have I used?
- Did I pick my best one yet?

Then: pick the best one so far and go to the next part.

Remember: exploring counts. If I learned something, that is progress.

Take a break. Walk or cook with a podcast on.

----------------
STEP 3: END OF DAY (1 minute)

Write one line:
"Today I finished / learned ______."

----------------
(Optional) If I'm chatting with AI, I can type:
stuck = tell me where I am and what to do next
park = save this idea on one line
done = give me one line on what I did today
