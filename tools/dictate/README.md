# Dictate

Hold **Right Ctrl**, talk or whisper, let go. Words appear where your cursor is.
Runs on your PC. No account, no cloud.

1. Install Python from python.org (tick "Add to PATH").
2. Double-click `run.bat`. First run sets up and downloads the model.
3. Keep the window open (minimize it). Hold Right Ctrl and talk.

Change the key or model at the top of `dictate.py`.
